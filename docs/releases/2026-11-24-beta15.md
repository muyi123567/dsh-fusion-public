# 鲸 0.2.0-beta.15：多机环境证据与开放连接器

日期：2026-11-24。候选包：`dsh-fusion-0.2.0-beta.15.tgz`。

## 本版重点

beta.15 在 beta.14 原生面板基础上，补齐多机环境一致性与开放接入：

- **云盘连接器**：Google Drive、OneDrive、Dropbox、WebDAV/Nextcloud；列表/搜索/
  拉取，operator-only `approve` scope 下的单文件导出；
- **通知适配器**：dsh-im（`sendChecked` 回执）、webhook、Slack、飞书、钉钉、
  Telegram、Discord；失败隔离、事件过滤、最近 100 条元数据回执；
- **远端信任表**：hostId 绑定 Ed25519 公钥，manual/TOFU，未信任/验签失败一律
  unknown；
- **主机加入包**：一次导入远端清单、公钥信任与期望环境，加入包摘要/签名/公钥绑定
  三重校验；
- **预设中心**：可安装 DSH Skill `whale-fleet-ops`、热门插件清单与配置模板；
- **配置热备**：profile/cordis/lock/鲸群状态快照、校验、恢复演练与显式恢复，
  私钥和凭据排除；
- **环境对齐执行**：本机 install/update/enable，planDigest 复核、人工/approve scope
  批准、失败逆序回滚、执行后强制重采集；
- **统一状态**：`whale_status` 一次返回主机、漂移、信任、审批、连接器、通知、
  预设、热备与对齐摘要；`whale_doctor` 扩展对应检查。

## 兼容性

- DSH 安装范围：`>=0.2.0-rc.2 <0.3.0`；
- recommended：`0.2.2-rc.5`；
- tested：`0.2.2-rc.5`、`0.2.3-alpha.2`；
- Node：`>=24.9.0`。

beta.15 的主要运行验证在 DSH `0.2.3-alpha.2` 隔离 profile 完成；stable 行为沿用
beta.14 的 `0.2.2-rc.5` 实机证据。

## 安装

```sh
dsh plugin --profile web add ./dsh-fusion-0.2.0-beta.15.tgz
```

重载 profile 后从侧栏「鲸」打开。MCP、云盘、通知、热备等能力默认关闭或只读，
按 README 配置后启用。

## 验证摘要

- 插件 513 项、原生面板 74 项通过（本版收口前）；
- TypeScript、插件构建、Vite 构建、release 校验通过；
- 云盘 WebDAV 实机拉取/上传，sha256 一致；
- 通知六路本地 204 回执与 dsh-im `sendChecked` 单测；
- 远端信任真实双钥测试与 0600 持久化；
- 配置快照/恢复演练，`host-key.pem` 排除；
- 环境对齐 fixture 实机启用，after=match、状态 succeeded；
- `whale_status`/`whale_doctor` 在 alpha 隔离 profile 返回完整子系统摘要。

## 边界

- 真实 Google Drive/OneDrive/Dropbox/Slack/飞书/钉钉/Telegram/Discord 账号未用生产
  凭据验证；
- 环境对齐 v1 仅本机；真实包源 install/update 尚未验证；
- 配置热备是本机快照，不含跨机复制；
- 入站命令、删除/移动云盘文件、远端执行代理未开放。
