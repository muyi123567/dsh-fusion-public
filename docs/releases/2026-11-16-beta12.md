# DSH Fusion 0.2.0-beta.12

本版为公开 beta 预发布。安装范围、已验证能力与未验收项目分别记录。

## 变化

- 增加 Host 所有者、共享模式和每台机器的并发配额，启动中的任务计入容量。
- 从 DSH 原生 AgentTeam 的 sequenced 投影读取非空任务板，保留任务 ID、
  revision、负责人、依赖、ready、写入范围和警告。读取失败不伪装成健康空板。
- 原生与 legacy 数据使用独立命名空间；仅旧接口缺失且原生能力可用时允许降级。
- 修复重复派发回执、单子聚合身份丢失、取消/inspect 竞态及恢复证据门。
- 完成回执绑定任务和节点；相同证据的新空值使旧结果失效，
  多子任务分别要求回执、stdout 与 stderr，不允许兄弟证据补位。
- AgentTeams companion 升级为未修改的官方 0.1.30，保留退役成员安全守卫。
- Vitest 升为 4.1.12，修复审计命中的 2 critical / 3 moderate 开发依赖公告。
- 产物附带实际打包依赖的许可声明，并要求发布校验检查该文件。
  AgentBus 保留发布方的 MIT 声明，归档附完整条款和来源说明，不虚构版权人。

## 运行要求

Node >=24.9.0；包管理器 pnpm 11.21.0。
DSH 安装范围 >=0.2.0-rc.2 <0.3.0；推荐 0.2.2-rc.1，兼容基线 0.2.0-rc.2，
0.2.2-rc.3 为候选。companion：Room 0.7.0、AgentTeams 0.1.30、
AgentBus 0.1.1 兼容补丁版。版本范围不是完整业务兼容承诺。

## 已知限制

- 未调用付费模型；真实模型任务、完整双 Session 协作、第三台节点、
  OS 重启、完整崩溃窗口恢复及升级回滚/热卸载矩阵仍待独立验收。
- 产物 doctor 检查构建结构。运行 doctor 会受真实 fleet 节点和可选来源配置影响；
  未配置节点不应解释为全部业务已验收。
- Host owner 是资源声明，不能替代成员 ACL 或系统账号隔离。writeScopes 只是提示。
- W2 的 execution attempt/receipt 新契约、W3 的 fencing 租约、
  W4 的独立 reviewer 与精确 HEAD/diff 证据、W5 的受限候选补丁自改进尚未交付。
  本版恢复路径和幂等缺陷修复不代表整个 W2–W5 已完成。
