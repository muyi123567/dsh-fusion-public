# 🐋 鲸 0.2.0-beta.13

展示名称定为「鲸」。鲸群表达团队之间的关系，磷虾表达细任务与子代理；
保持真实身份与来源，不把隐喻当作调度语义。

三版代码候选已完成比较：A鲸群航图、B深海舰桥、C洋流矩阵。两位独立审查者均
推荐B作为运维默认首页，A/C保留于独立交互展厅。正式插件只加载选定布局。
[比选与修正](../design/2026-11-16-whale-comparison.md)说明截图证据与取舍。

本版新增原生概览，统一侧栏与深海主题；保留原任务/会话/运行/配置/终端。
修正来源失败、手机滚动、过小字号和触达、正常与异常配色、旧全局样式外溢；
只读展示模型补齐聚合子状态、未观测任务声明与缺失依赖去重。

后端工具/API/包名保持dsh-fusion；模型写入和终端仍默认关闭。真实模型任务、
完整多集群业务协作、fencing租约、精确代码审核与自改进仍不在本版交付范围。

最终测试、三视口交互审查、宿主安装与包哈希由发布收据记录。

## 验证与发布

授权Instabox：1103项源码测试与27项Node契约通过；typecheck、构建、
产物doctor29/29、package契约、Chromium E2E3/3、依赖审计均通过。
三个候选×三个视口的9个场景自动检查0失败，同模型摘要一致，搜索、团队选择、
任务/主机详情、合法空海域、未观测与断线均有交互证据。
两位独立审查者对本轮截图给出比较意见，修正见设计审查文档。

同一包已在rc.1与rc.3干净profile安装四件套、启动并用真实浏览器打开鲸面板。
宿主样式开关前后一致、焦点约束与返回、390px滚动与嵌套导航Escape完成验证。
新profile先正常确认上游预览版提示、关闭可选模型引导，不调用模型。
运行时无真实Fleet节点，不把空profile启动等同完整多机业务验收。
矩阵的有意横向滚动经截图审查；不声明全量无障碍合规或所有断点/抽屉穷举验收。

[三版交互展厅](https://whale-panel.whale-muyi123567.workers.dev/)只含合成数据，
没有任务派发和机器凭据。GitHub Release提供tgz、SHA256SUMS和验证收据。
使用方仍用 dsh plugin --profile web add ./dsh-fusion-0.2.0-beta.13.tgz 安装。
