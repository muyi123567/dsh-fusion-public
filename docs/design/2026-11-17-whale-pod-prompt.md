# 鲸群海域动画提示词 v1
前置依据：2026-11-17-magpie-research.md；严格在调研完成后形成此提示词，后续动画实现以此为基准。

为“鲸 · Whale”多机多团队Agent插件制作可常驻的交互海域。场景本身承担团队态势与选择，不是页面顶部的宣传视频。延续已获用户认可的座头鲸真实纹理、喉沟、胸鳍与分叉尾鳍，使用已有0.93MB/19999三角轻量模型。

视觉：全幅深蓝海域占主要画面。3只前中后层次分明的鲸，大小、位置、摆尾相位不同。少量颗粒、体积感光束、淡尾迹，水体有深度，鲸轮廓完整，UI用轻薄深色浮层，不遮住鲸头、胸鳍和尾鳍。不使用霓虹连线或把鲸画成卡通图标。手机重新构图，始终留出鲸群可见区域。

场景A“深海遨游”：镜头稳定，以斜侧面观察；鲸群缓慢巡游、有微小升沉、转向限幅。初次进入可以柔和下潜一次，之后至少90秒自然延续，不每36秒重播入水、不瞬移复位、不让鲸游出画面。各鲸共享模型/纹理，用独立相位获得生命感。

场景B“海面呼吸”：用户可主动切换。镜头以海面斜俯视构图，看到鲸背接近和浮出水面、呼吸孔露出、短促雾状喷气、喷雾散去、鲸背回潜与环形涟漪。喷水表现为呼吸喷雾，禁止永久水柱、禁止水下喷泉、禁止所有鲸同步喷水。自然呼吸不等于任务完成。切换场景保持团队身份/任务选择和累计时间连续。

工作映射：每只鲸对应真实团队ID，最多3只精细鲸，更多团队通过可读选择器切换窗口，不能伪造团队。活动任务可用该鲸周围有限磷虾粒子与轻尾迹提示；等待/受阻降低任务粒子移动并显示文字；完成统计来自真实快照，不能因为动画结束而增加。数据陈旧/未观测时停止工作语义提示，保留生命感并明确“上次观测/未观测”。零团队只显示安静海域和连接入口。

交互：点击鲸或其对应名称选择团队；选中后以边侧浮层展示同ID任务/主机/证据入口；任务详情正常可点且键盘可达。海域保持主体，任务列表按需展开，不能把大列表常驻堆在鲸画面下。底部紧凑导航可切换团队、任务、主机、关注。提供深海/海面、暂停/继续、自动/平衡/节能/静态。

轻量：单Canvas/单WebGLRenderer，复用几何和纹理，不为每鲸创建canvas，不用高成本实时流体/阴影/重型后期。平衡上限24fps、节能上限15fps；降低DPR/水网格/粒子，不把所有鲸删成一只。动画时间仅在可见运行时推进，隐藏/离屏/暂停停止调度；静态、减动画、省流模式无WebGL初始化。组件卸载完整释放，GLB失败海报回退且任务仍可操作。

验收：相同模型/光照对照重/轻素材；desktop1536/1280与mobile390实帧；深海3鲸/海面非同步喷雾；90秒无重置；单Canvas；暂停/隐藏/离屏停帧；静态无WebGL；切换不丢团队ID；合成演示明显标识；不宣称真实GPU能耗或跨集群业务已验收。
