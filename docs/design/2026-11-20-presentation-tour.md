# 任务优先前端快速展示

## 目标

为独立任务优先设计稿提供一段约15秒的显式启动导览，让评审快速理解列表、任务缺口和证据阅读顺序。

## 方案与取舍

- 被动循环动画不需要用户操作，但容易遮挡阅读、打扰原生面板，也难以让讲解者控制节奏。
- 点击后逐屏手动切换最可控，但不适合现场快速展示。
- 采用显式启动的一次性定时导览；普通用户操作立即退出，减少动态效果偏好下改为手动逐步浏览。兼顾展示节奏和用户控制。

## 展示顺序

1. 任务列表与需关注分组。
2. 打开一条合成的 verifying 任务，原状态保持待验收。
3. 短暂强调“独立审查结论未提供”。
4. 定位到已有来源证据并轻微强调。
5. 停留并明确结束语：“证据可读；独立审查未提供；未执行任务”。

每阶段约3秒，总计约15秒。用户可开始、暂停、继续、重播；任何面板内指针、键盘、输入或滚动操作都会退出导览并恢复普通交互。切到后台时暂停计时。

导览只切换本地演示面板，不修改fixture，不请求真实任务，不展示成功或远端执行动画，不抢键盘焦点。
系统启用 `prefers-reduced-motion` 时不自动计时、不做位移动效；用户可逐步切换同样的静态阶段。
动画只出现在独立审稿外围和本地合成设计入口，不进入生产 native 正文。
