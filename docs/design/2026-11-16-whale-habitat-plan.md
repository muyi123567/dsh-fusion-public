# 鲸栖海域：轻量持续面板
用户已认可鲸形真实性，要求五路并发做成轻量且持续运行的面板。
保留原有舰桥和36秒入水预览，新增可切换的持续海域概览，并复用同一WhalePanelModel和回调。

1. 素材：离线简化网格和纹理，保留原模型和许可，生成专门面板GLB。目标<1MB，不以目标冒充测量。
2. 动作：一次平滑入水后持续小幅巡游，姿态/光束不按36秒重置，活动状态来自收到的快照。
3. 界面：真实鲸占有可见海域，任务、团队、主机入口保持清晰可读，合成展示明确标识。
4. 省电：单一Canvas；平衡24fps/节能15fps；按帧预算降级；页面隐藏或离屏停止调度；静态模式不加载3D；尊重减动画。
5. 独立验收：云端冻结构建、桌面/手机、长时运行、暂停/隐藏/离屏、空/陈旧来源、低性能模式和资源回收。

开发只在买机入口后的CUE隔离工作树，所有依赖执行、模型处理和渲染测试仅在Instabox。
每路独立写集，父代理拥有场景整合、原生插件懒加载入口、打包与发布。
