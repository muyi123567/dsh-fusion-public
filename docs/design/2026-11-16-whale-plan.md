# Whale panel implementation plan

Goal: 三版代码原型对比后交付实用的深海鲸面板。
Architecture: 复用现有快照，建立只读展示投影，三个独立视觉组件使用统一props。
Tech Stack: React18、TypeScript、Vite、CSS、SVG；不新增依赖。
Spec: 2026-11-16-whale-brief.md。

- [ ] 建立共享只读数据模型与合成展示数据，锁定来源和未知状态。
- [ ] 三个不同信息架构的可交互候选，独立写集并行实现。
- [ ] 集成显式设计展厅、远端构建，获取同数据桌面/手机截图。
- [ ] 对照截图进行视觉、交互、可访问性与真实性独立审查，修复问题。
- [ ] 选定方案接入正式概览，统一鲸品牌与深海主题，保留其他工作流。
- [ ] Instabox类型/单测/浏览器/真实宿主/产物门禁，写比选结论。
- [ ] 推送原私仓和公开仓，发布带预构建包与校验值的下一版预发布。

Risk focus: 无数据时不生成假鲸/假关系；不改变写入权限；不全局污染DSH宿主样式；
动态长列表有界；键盘与reduced-motion可用；不丢失旧任务/会话工作流。
