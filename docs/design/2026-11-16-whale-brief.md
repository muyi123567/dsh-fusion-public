# 🐋 鲸：深海工作面板

用户命名：鲸。鲸之间的联系表达团队协作，磷虾表达子代理和细碎任务。
保持机器、团队、任务的实际身份，不把 Host 等同 Team，不伪造跨团队关系或集群。
开发：CUE，经买机入口；构建、截图、交互和回归测试：Instabox。

## 三版代码候选

A 鲸群航图：海底等深线、鲸群分布、来源明确的关系、磷虾任务点。强拓扑感。
B 深海舰桥：鲸群态势、主机资源和异常队列组成运维工作台。强可读性和操作效率。
C 洋流矩阵：团队横向泳道，细任务形成可选择的磷虾带。强并行任务扫描。

同一数据与三组视口比较。先写可运行代码原型，截图后进行独立审查。
不先生成图片作为页面，不将静态截图伪装成交互界面。
不新增后端权限，不更改 package/tool/route 名称，显示品牌采用「鲸」。
来源未连接、合法空板、未知任务归属、陈旧状态分开呈现。

## 设计语汇

深海蓝黑底、冷青蓝作为关系与聚焦色；暖珊瑚仅用于受阻/异常。
文字高对比，正文14px左右，次要信息最小12px。控制最小触达40px。
低幅度洋流与呼吸动画，支持 prefers-reduced-motion。键盘可操作和清晰焦点。
SVG 作为关系图标与数据图形；不把随机点云、漂浮鲸数或动画当作运行证据。
