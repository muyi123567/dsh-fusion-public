# 鲸入深海 · 动态原型
用户否决抽象鲸图标，要求可再分发素材与代码实现的真实鲸鱼入海动态。
本轮先交付独立全屏动态预览，保留原舰桥入口；不改任务、主机、调度及插件 API。

## 设计
使用 Grab3D CC0 纹理座头鲸 light GLB（3.7 MB），Three.js 实时绘制。
镜头在水下仰视：鲸尾接近水面，鲸体弯曲摆尾入水，随后向蓝色深海下潜。
海面细波、透射光束、漂浮颗粒、尾部气泡与入水环纹构成环境。
页面只保留品牌、返回舰桥、播放/暂停、重播、进度和素材署名。
尊重减动画；不可见时暂停，关闭时释放资源；WebGL 不可用时明确静态回退。
独立入口 whale-dive.html，不将 3D 依赖引入现有插件面板。

## 实施顺序
1. 保存素材、许可、来源与 SHA256；模型不从第三方运行时加载。
2. CUE 实现场景、React 播放器和独立 Vite 入口。
3. Instabox 安装精确 Three.js 依赖并更新 lockfile，构建、检查桌面与手机实帧。
4. 审查鲸形、朝向、下潜连续性、光影、播放控制、减动画与资源回收。
5. 将同一构建快照推送 GitHub，更新公开预览白名单与 CSP，检查线上实帧。

## 验收边界
这是实时视觉原型，不宣称流体动力学模拟、真实多团队执行或真实海洋摄影。
