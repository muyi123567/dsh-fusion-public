# 鲸：DSH 原生面板候选

这是针对原生 DSH 的面板改版。入口注册到 DSH 右栏，主聊天区保留在旁边。
本阶段采用可观察的任务、主机、团队与海域视图；执行任务、终端登录与配置变更仍由已有能力负责。

## 日常使用

1. 选择 DSH 会话，从侧栏「鲸」或右栏添加页打开面板。
2. 默认查看任务。受阻、失败与待验收优先，按名称或归属搜索，按状态筛选。
3. 点击任务、主机或团队进入面板内详情；返回按钮或面板内 Escape 回到列表。
4. 需要查看协作意象时切换海域，查看鲸群、海豚、磷虾与航标。面板关闭或离开海域时停止场景。
5. 关闭、调整宽度与标签管理交给 DSH，主题和字体跟随宿主。

面板跟随宿主会话停靠，但当前快照是 Fusion 全局来源；不会把全局列表写成当前会话专属数据。
首次打开没有会话时显示选择会话提示。缺少右栏服务时显示宿主不支持的提示。

## 视觉取舍

使用 DSH 自身语义色、字体、细分隔线与紧凑控制，默认列表视图。
鲸意象集中在可选海域，不占用每项任务的主要操作空间。
真实来源、演示数据、来源失败、保留的旧快照与来源未提供分别提示。
不以动画推断成功：喷水是呼吸，SSH 可达不代表终端登录，子代理空闲不代表完成。

上游依据为 deepseek-ai/deepseek-harness：
- packages/client/ui-sidebar-right 的 tab 注册、正文 slot 与 openTab
- packages/client/ui-sidebar-files 的原生接入方式
- docs/web-styling.zh.md、ui-theme/base.css 与 ui-primitives 控件习惯
- 固定研究版本：39163dd30f703a79079e2d2446545cff3c453738

## 加载边界

入口仅请求工作面板。海域界面与 3D 渲染各自为独立 DSH 原生模块，
只在用户选择海域时请求。加载错误保留其它列表视图，并提供局部重试。

桌面由 DSH 推开布局；低于宿主窄屏阈值时，右栏自身可能进入全屏。
插件不创建额外遮罩，也不修改宿主全局背景和滚动。
