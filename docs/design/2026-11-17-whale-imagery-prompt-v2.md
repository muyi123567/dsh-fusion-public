# 海域意象提示词 v2：由实景承载工作之意
沿用已完成的Magpie研究与v1提示词。中文“意象”在这里指：可感的海洋形象通过特定动作/情境承载工作含义，形成统一可理解的场景，不是只替换动物图标。这是产品设计隐喻，不把海豚、海鸥的产品含义冒称古典文学固定象征。
鲸群=Agent团队；海豚=明确标为subagent的会话；磷虾=细任务/队列；海鸥=有周期/触发记录的定时任务；远端SSH=通往远海的航标和航道。

## 实际事件与镜头动作
启动/首次加载：海面由暗到明，场景缓入；来源未到只显示海雾与等待来源。首次快照按既有身份安置鲸群，不能把首帧所有online/completed当新连接/新完成。
任务queued：对应团队附近磷虾缓缓聚集，保留task ID与文字。
queued/claimed→running：对应鲸轻微起航、磷虾沿短流线汇聚；首次快照已有running只画持续状态，不追播开始。
running→verifying：动作收束、磷虾停留，明确待验收，不庆祝。
→completed：只有观察到新完成边沿时回流一圈并出现可读证据入口，生命呼吸喷雾不能充当成功证明。
→failed/blocked：工作粒子停留、轻琥珀提示，不坠落/爆炸/死亡等夸张情节。
SSH远端已配置但尚未观测：远处暗航标，等待来源。transport包含ssh且online只代表“SSH主机可达”；不是PTY会话、认证握手或任务执行成功。
SSH已观测offline→online：航标由暗转明、短航道涟漪；online→offline：航道中断且标注原因；来源stale时显示失去观测，不冒称主机离线。
subagent running：海豚随队或离群协作；running→idle仅标本轮停止，不标任务完成；failed明确错误；不存在origin=subagent记录不造海豚。
scheduled task等待：海鸥在空中缓慢盘旋；真实lastRunId/触发状态变更才出现一次按期掠过。首帧既有lastRun不重播；无定时来源不画假海鸥，显示未接入。
所有动物可读名称/对应ID在浮层查看；不要求用户仅凭颜色理解。当前预览可以通过显式“情境演示”推进合成事件，必须清楚无真实SSH/任务派发。

## 轻量与验收
保留v1真实鲸纹理、单canvas、共享几何、24/15fps、后台停帧、静态零WebGL。
不重演历史、不按随机timer制造任务活动；状态导演纯函数比较快照并有界去重；fresh→stale抑制工作事件，恢复只接当前状态。
提供事件映射表、场景说明和对应测试。海鸥/海豚只有真实或明确合成数据驱动；任务场景状态和业务执行证据分开验收。
